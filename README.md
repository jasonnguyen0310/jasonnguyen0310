I build the infrastructure that lets AI agents do real work safely.

At AWS I work on a Model Context Protocol (MCP) server that gives AI agents secure, per-user access to Salesforce CRM data. It grew from a pilot in early 2026 to 28K monthly users and 31M tool calls a month.


What I care about is the gap between an agent demo and an agent people can trust in production. That's the work I do: validation that stops bad writes before they land (failed updates down 99%), rate limiting that holds up under a 35x traffic surge, staged rollouts with kill switches, and on-call ownership from page to root cause.

I also build with agents every day. I run several coding agents in parallel with review agents as pre-merge gates, and about half my commits this year were agent-assisted.

Stack: TypeScript, Python, GraphQL, AWS (Lambda, ECS Fargate, Step Functions, DynamoDB, Bedrock AgentCore), Salesforce.

Outside AWS I invest, build companies, and run a community.
